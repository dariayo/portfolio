# daria.dev — portfolio

Static portfolio of Daria Shevchenko, Backend Developer (Java / .NET).

## Local preview

Open `index.html` in a browser. No build step or dependencies are required.

## GitHub Pages

1. Create a GitHub repository and push this folder to its `main` branch.
2. In **Settings → Pages**, choose **GitHub Actions** as the source.
3. Every push to `main` will deploy the site automatically through `.github/workflows/deploy-pages.yml`.

The site will be available at `https://<username>.github.io/<repository>/`.
